Before you start
  • 🌐 Use Chrome or Firefox on a laptop. Safari works but is slower. Mobile devices are not recommended — the Python runtime needs ~30 MB of memory.
  • ⏳ First load takes 10–20 seconds. A Python environment is being set up inside your browser. Subsequent visits are faster thanks to caching.
  • 💾 Your work is saved in your browser only. If you clear your cache or switch browsers, your progress is lost. Use File → Download to save a copy of your notebook.
  • 📥 Save & resume. At the end of each session, use File → Download to save your notebook. Next time, upload it via the file browser to continue where you left off.
  • ▶ Run cells top to bottom. Later cells depend on earlier ones. If something breaks, restart the kernel and run all cells again.
